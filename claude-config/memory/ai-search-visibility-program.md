**Core discovery (2026-07-03, via ChatGPT scraper replication):** AI assistants answer local queries in two distinct modes. (1) "Best X company in {city}" research phrasing → web-search citations, where Rank AI content already wins (narestco/homepride cited rank 2 on chatgpt/gemini/perplexity for several). (2) "My house flooded, who do I call" emergency phrasing → ChatGPT's local-business entity module fed by GBP-linked sites + an official **Yelp data partnership** (entity URLs carry utm_source=gbp/gmb and yelp_feed openai tags) — content barely matters there; listings do. Results are volatile run-to-run (two runs = two different top-6 lists).

**Shipped 2026-07-03 (all committed + deployed):**
- `/emergency/` indexable pages on narestco/homepride/flood-fixers + starter (quotable capsules, honest response claims — only narestco says "60 minutes" since only it claimed that; FAQPage schema; nav+footer links; llms.txt emergency line).
- **IndexNow** auto-ping on every sync-deploy (`build_site.py indexnow --slug X` for manual). Keys self-generated, stored in clients/{slug}.json + sites/{slug}/public/{key}.txt. All 3 live sites accepted (202) — narestco/homepride via www.bing.com/indexnow after api.indexnow.org cached a premature 403; that cache self-heals on future deploy pings.

NaRestCo baseline: present in 2/23 ranking list pages; gaps = Yelp Seattle/Bellevue collections (#1 ranks), Expertise.com (free application ×3), seattle-adu.com guide series (one pitch covers 3 cities).
- **strategist.py citation loop**: diffs latest-vs-prior scan per (engine, query) → newly/lost/never cited → emits `ai_citation_fix` actions (per-engine playbooks: ChatGPT→Bing Places, Perplexity→Yelp, Gemini→GBP+reviews) deduped into marketing_action_plan; wins in run log. Emergency phrasing seeded into default scans + custom queries for all 3 clients.
